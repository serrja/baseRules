# 🧭 Руководства к формам

Инструкции автору находятся здесь, вне устанавливаемого дерева `templates/obsidian`.
[Общие правила](../knowledge.md) владеют чистотой Markdown, прогрессом и внешним контрактом;
[карта совместимости](../template-compatibility.md) описывает переход.

Руководства по категориям сопровождают соответствующие формы. Они не входят в manifest,
не устанавливаются в хранилище и не попадают в picker. Технические фикстуры находятся в тестах
`scripts/` и при необходимости `scripts/fixtures/`; это не пользовательские материалы.

- [Общие формы](common.md): заметка, оглавление, встреча, инструкция и проблема.
- [IT](it.md): направление, курс, урок, банк вопросов и структурный режим.
- [Университет](university.md): реальные программы, условия, работы и билеты.
- [Профиль и работа](personal-work.md): опыт, проекты, вопросы и внешние материалы.
- [Notebook](notebook.md): отдельный незавершённый браузерный каркас.
