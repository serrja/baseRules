# Working document tree

One outline to copy when a real project needs shared documents. Do not pre-create fictional work.

```text
materials/
  personal/                 private personal attachments
  learning/
    university/             preserve existing access and subject IDs
    it/                     actual learning attachments only
  work/
    <project_name>/
      context/              native brief and requirements
      decisions/            native decision records
      meetings/             native meeting notes
      deliverables/         native documents and exported deliverables
      assets/               attachments
```

Code: `<git repository URL>`. Knowledge: `<vault note path>`.
Drive folder: `<verified private folder URL>`. Authoritative native Doc: `<verified document URL>`.
Use English snake_case names. Verify permissions before every move; keep object IDs.
