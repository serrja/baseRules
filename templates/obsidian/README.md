## Единый стиль

Один H1, короткие H2 с умеренными эмодзи, понятный возврат и ровно один владелец каждого развёрнутого объяснения. Источники сохраняются в HTML-комментариях; формулировки вопросов видимы. Конспект объясняет тему полностью, а программа курса связывает теорию, упражнения, контрольные точки и итоговый проект.

Технический банк сохраняет четыре колонки: «Вопрос», «Короткий ответ», «Развёрнутый ответ», «Типичные ошибки». Подробные объяснения и ошибки находятся в каноническом конспекте. Проектные уточнения сохраняют отдельную таблицу «Вопрос / Ответ». Существующие IDs и варианты вопросов не теряются при переносе.

## Установка

Устанавливайте только записи `kind: markdown` из manifest, сохраняя категории. README, manifest, notebook и весь репозиторий не копируются в меню Markdown-шаблонов. `{{title}}` — поддерживаемая переменная; остальные поля являются ручными подсказками.

Ближайший `project.json` определяет раздел, а формы родителей наследуются. Возможности подписей и автоматического возврата проверяются по фактическому коду установленного плагина; одинаковый номер версии не доказывает одинаковое поведение.

Notebook открывается в подготовленной браузерной среде по проверенной ссылке. Markdown-плагин его не исполняет. Шаблон намеренно содержит незаполненное упражнение и не может считаться готовой практикой до заполнения и запуска.

При миграции близкие локальные формы объединяются с канонической формой после сохранения уникальных полей. Один тип не появляется в меню одновременно как несколько одинаковых копий. Прогресс существующих заметок и приватность материалов сохраняются.
