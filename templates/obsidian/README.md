# Obsidian templates

Десять переносимых шаблонов содержат только подсказки, без личных фактов и готовых результатов.
Установка описана в [правилах знаний](../../docs/knowledge.md).

| Категория | Шаблон | Когда использовать |
| --- | --- | --- |
| О себе | [Личная страница](personal/profile.md) | Сохранить выбранные сведения и навигацию |
| О себе | [Опыт](personal/experience.md) | Описать подтверждённый вклад и его ограничения |
| О себе | [Интересы](personal/interests.md) | Связать интерес с практикой и источниками |
| О себе | [Цели](personal/goals.md) | Определить критерий результата и следующий шаг |
| Университет | [Предмет](university/subject.md) | Собрать существующие материалы предмета |
| Университет | [Конспект](university/note.md) | Сохранить порядок объяснения, формулы, пример и источники |
| Университет | [Лабораторная](university/laboratory.md) | Описать фактическую программу, измерение или модель и проверку результата |
| IT | [Техническая тема](it/topic.md) | Освоить идею через практику и самопроверку |
| IT | [Технические вопросы](it/technical_questions.md) | Собрать вопросы со ссылками на объясняющие темы и практику |
| Работа | [Рабочий проект](work/project.md) | Подтвердить роль, решения, результаты и рассказ для интервью |

Создайте заметку в существующем разделе и вызовите **Шаблоны раздела**. В project-scope 1.3
категории видны в пути шаблона: `baseRules/personal`, `university`, `it`, `work`.
Плагин рекурсивно читает настроенные папки; устанавливаются только десять файлов заметок,
без этого README. `{{title}}` подставляется плагином. Все `[Заполните: …]` — ручные подсказки,
а не переменные; добавьте полную wikilink-ссылку на ближайшее оглавление и проверенный Drive URL.
Не фиксируйте в публичном шаблоне имя личного каталога. Ссылку на новую заметку и отметку
прохождения храните только в ближайшем оглавлении.

Учебные формы сохраняют роль существующих оглавлений и порядок материала; адаптируйте будущую
заметку к требованиям предмета. Старые билеты и экзаменационные заметки остаются на своих местах.
Шаблон технических вопросов относится к IT; конспект не требует таблицы для собеседования.

Project-scope 1.3 показывает имя файла, не metadata display-name. Для русского пункта
«Технические вопросы» допустимо установить единственную копию `it/Технические_вопросы.md`
из `it/technical_questions.md` и записать преобразование пути в private provenance.
Байты остаются исходными, параллельная английская установленная копия не нужна.
