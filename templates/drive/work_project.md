# Work project documents

One outline for an existing project with a real need for shared documents. Do not pre-create
fictional work, employers or deliverables.

```text
work/
  <real_project>/
    context/                   native brief, requirements and project description
    decisions/                 decisions, alternatives and meeting notes
    materials/                 source attachments and references
    deliverables/              native final documents and exported deliverables
```

Meeting notes stay in `decisions` until their volume justifies a separate folder. Use English
snake_case names. Read the [root mapping](README.md) and preserve object IDs/access when moving.

[interview preparation](../obsidian/work/interview.md). Each detailed explanation has one owner;
this outline only organizes linked documents and does not modify a résumé.
